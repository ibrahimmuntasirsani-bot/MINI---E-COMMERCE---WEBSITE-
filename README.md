## MINI E-COMMERCE WEB APP

A fully functional **mini e-commerce website** built using pure **HTML, CSS, and JavaScript**.  
This project simulates a real online shopping system with cart functionality and dynamic price calculation.

---

##  LIVE FEATURES

-  Product listing system
-  Add products to cart
-  Remove items from cart
-  Real-time total price calculation
-  Instant UI updates (no reload)
-  Responsive modern design
-  Single-file lightweight architecture

---

##  BUILT WITH

- HTML5
- CSS3
- Vanilla JavaScript (No frameworks)

---

##  PROJECT LOGIC

This project demonstrates core frontend engineering concepts:

- DOM manipulation
- Array-based cart system
- Event handling
- Dynamic rendering
- State management (frontend level)
